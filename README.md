# FitneZz · 智周万物

一个把「训练 / 组间歇 / 饮食 / 身材目标」收在一处的健身记录 App。

> 本仓库只放**产品说明与公开数据表**，不包含任何源码、密钥或用户数据。

## 它解决什么

练完一组要记重量、要掐组间歇、要记吃了什么、要盯体重——现在散在备忘录、闹钟、计算器和相册里。
FitneZz 把它们放在一个流程里，打开就知道今天练什么。

## 核心功能

| 功能 | 说明 |
|---|---|
| 任务计划 | 推/拉/腿等分组，记录动作、组数、次数、重量；练完直接勾掉 |
| 组间歇 | 手机闹钟式倒计时，锁屏与后台都能提醒；只在到点时震动一次，不响铃 |
| 饮食记录 | 按克数自动换算热量与三大营养素；支持「米饭 200 克」这类自然语言 |
| 身材记录 | 体重/围度/BMI/自定义指标，折线、柱状、K 线三种视图 |
| 打卡与成就 | 日历式打卡、连续天数、等级与徽章 |

## 商业化原则

**普通用户不付费也能用完整功能。** 会员只提供更细致的服务：
自定义配色与照片背景、语音录入、每周补签、数据导出、多设备同步等。
